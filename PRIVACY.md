# Privacy policy

MirrorDL collects no personal data. It has no account, no tracking, no analytics and no ads.

It connects only to:

- **the download links you give it**, to check them and download the file;
- **api.github.com**, once when the window app starts, to see whether a newer version exists. Only
  the version from GitHub does this; the Microsoft Store version gets its updates from the Store.
  Like any website, GitHub receives the usual request data, such as your IP address.

The files you download, and MirrorDL's progress files next to them, stay on your computer. MirrorDL
sends nothing about them anywhere.

Questions: [open an issue](https://github.com/Nawid3333/MirrorDL/issues).
